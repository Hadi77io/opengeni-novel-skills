# مبادئ مشتركة عبر المهارات

هذه المبادئ ليست بديلاً عن المهارة الفصلية، لكنها تساعد الوكيل عند تداخل الوحدات:

| المبدأ | طريقة الاستخدام |
|---|---|
| الممارسة قبل انتظار الإلهام | اقترح مخرجاً صغيراً قابلاً للإنجاز ثم حسّنه بالتكرار. |
| الإظهار بدل الإخبار | ابحث عن فعل أو حس أو حوار أو تفصيل يتيح للقارئ استنتاج المعنى. |
| القيد يولّد حلولاً | استخدم طولاً أو منظوراً أو شكلاً محدداً عندما يتشتت الكاتب. |
| السبب والنتيجة | لا تكتف بتجاور الأحداث؛ اسأل ما الذي سبّب كل تحول وما الذي تغيّر بعده. |
| الشخصية شبكة أبعاد | افحص الجسد والمجتمع والنفس والصوت والعادة، ثم أظهرها في موقف. |
| الحوار فعل | لكل جملة غرض أو مقاومة أو كشف أو تغيير، وإلا فاختصرها أو احذفها. |
| الوصف انتقاء | اختر التفاصيل التي تخدم منظور الشخصية أو التوتر أو حركة المشهد. |
| القارئ شريك | اترك مساحة للاستنتاج، لكن لا تجعل الغموض نتيجة نقص المعلومات. |
| الصوت والإيقاع | اقرأ النص بصوت مسموع عند اختبار النبرة والسرعة والانتقال. |
